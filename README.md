# 🌦️ Weather App

A simple and responsive **Weather App** built using **HTML, Tailwind CSS, and JavaScript**. This app allows users to search for a city and view weather details in a clean UI.

---

## ✨ Features:

* 🌍 Search weather by city name
* 📱 Responsive design
* 🎨 Clean and modern UI using Tailwind CSS
* ⚡ Fast and simple interface

---

## 🛠️ Tech Stack:

* HTML
* Tailwind CSS
* JavaScript

---

## 📁 Project Structure:

```
weather-app/
│── index.html
│── README.md
```

---

## ⚙️ How It Works:

1. Enter a city name in the input field
2. Click the "Search" button
3. Weather data will be displayed (via API integration)

---

## 📱 Responsive Design:

* Mobile-friendly layout
* Centered card UI
* Adaptive input and button styles

---

## 🚀 Future Improvements:

* 🌐 Connect with real weather API (OpenWeather)
* 📊 Show temperature, humidity, wind speed
* 📍 Add current location weather
* 🎨 Add icons and animations

---

## 🎯 Purpose:

This project is created to practice **frontend development, UI design, and API integration basics**.

---

## ✅ Conclusion:

This Weather App demonstrates how to build a simple and responsive UI using Tailwind CSS.
It serves as a beginner-friendly project to understand user input handling and real-time data display.
